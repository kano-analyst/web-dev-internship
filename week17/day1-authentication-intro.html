🎯 What is Authentication?

Authentication is the process of verifying the identity of a user. It ensures that users are who they claim to be before granting access to protected resources.

Key Authentication Concepts:

  • Registration: Creating a new user account
  • Login: Verifying user credentials
  • Logout: Ending a user session
  • Session: Maintaining user state across requests
  • Password Hashing: Securely storing passwords
  • Remember Me: Persistent login functionality
  • Password Reset: Allowing users to recover accounts

Authentication vs Authorization:

Authentication Authorization
Who are you? What can you do?
Verifies identity Verifies permissions
Login/Register Roles/Permissions
Example: User login Example: Admin access

🚀 Laravel Authentication Options

1. Laravel Breeze (Recommended for Beginners)

Laravel Breeze is a minimal, simple implementation of all Laravel's authentication features including login, registration, password reset, email verification, and password confirmation.

Features:

  • Blade templates
  • Tailwind CSS styling
  • Simple and easy to customize
  • Perfect for learning

2. Laravel UI (Bootstrap/Vue/React)

Laravel UI provides Bootstrap scaffolding for authentication. Good if you prefer Bootstrap over Tailwind.

3. Laravel Jetstream (Advanced)

Jetstream includes more advanced features like team management, two-factor authentication, and API tokens.

💡 Tip: For this bootcamp, we'll use Laravel Breeze because it's simple, modern, and easy to understand.

📦 Installing Laravel Breeze

Step 1: Create a New Laravel Project

# Create new Laravel project composer create-project laravel/laravel auth-app # Navigate to project cd auth-app

Step 2: Install Laravel Breeze

# Install Breeze via Composer composer require laravel/breeze --dev

Step 3: Install Breeze Scaffolding

# Install Breeze with Blade templates php artisan breeze:install blade # Install NPM dependencies npm install # Compile assets npm run dev

What does breeze:install do?

  • Creates authentication routes in routes/auth.php
  • Generates authentication controllers
  • Creates Blade views for login, register, etc.
  • Installs Tailwind CSS
  • Sets up authentication middleware

Step 4: Configure Database

# Edit .env file DB_CONNECTION=mysql DB_HOST=127.0.0.1 DB_PORT=3306 DB_DATABASE=auth_app DB_USERNAME=root DB_PASSWORD=
💡 Tip: Make sure your XAMPP MySQL is running and create a database named "auth_app" in phpMyAdmin.

Step 5: Run Migrations

# Create authentication database tables php artisan migrate

Tables Created:

  • users: Stores user accounts
  • password_reset_tokens: For password recovery
  • sessions: Manages user sessions
  • migrations: Tracks migration history

Step 6: Start Development Server

# Start Laravel server php artisan serve # In another terminal, compile assets npm run dev
💡 Tip: Keep both terminals running - one for Laravel, one for Vite (asset compilation).

🔍 Exploring Authentication Files

1. Authentication Routes (routes/auth.php)

use App\Http\Controllers\Auth\AuthenticatedSessionController; use App\Http\Controllers\Auth\RegisteredUserController; use Illuminate\Support\Facades\Route; // Registration routes Route::get('/register', [RegisteredUserController::class, 'create']) ->name('register'); Route::post('/register', [RegisteredUserController::class, 'store']); // Login routes Route::get('/login', [AuthenticatedSessionController::class, 'create']) ->name('login'); Route::post('/login', [AuthenticatedSessionController::class, 'store']); // Logout route Route::post('/logout', [AuthenticatedSessionController::class, 'destroy']) ->name('logout');

2. User Model (app/Models/User.php)

namespace App\Models; use Illuminate\Foundation\Auth\User as Authenticatable; use Illuminate\Notifications\Notifiable; class User extends Authenticatable { use Notifiable; // Mass assignable attributes protected $fillable = [ 'name', 'email', 'password', ]; // Hidden attributes (not shown in JSON) protected $hidden = [ 'password', 'remember_token', ]; // Attribute casting protected $casts = [ 'email_verified_at' => 'datetime', 'password' => 'hashed', ]; }

3. Users Migration (database/migrations/xxxx_create_users_table.php)

public function up(): void { Schema::create('users', function (Blueprint $table) { $table->id(); $table->string('name'); $table->string('email')->unique(); $table->timestamp('email_verified_at')->nullable(); $table->string('password'); $table->rememberToken(); $table->timestamps(); }); }

🔐 How Laravel Handles Passwords

Password Hashing:

Laravel uses bcrypt hashing algorithm to securely store passwords. Passwords are never stored in plain text!

use Illuminate\Support\Facades\Hash; // Hash a password $hashedPassword = Hash::make('password123'); // Verify a password if (Hash::check('password123', $hashedPassword)) { // Password matches }

Password Validation Rules:

use Illuminate\Validation\Rules\Password; // Basic password rules 'password' => ['required', 'confirmed', Password::min(8)], // Strong password rules 'password' => [ 'required', 'confirmed', Password::min(8) ->letters() ->mixedCase() ->numbers() ->symbols() ],

📊 Database Tables Explained

1. Users Table Structure:

Column Type Description
id BIGINT Primary key
name VARCHAR(255) User's full name
email VARCHAR(255) Unique email address
email_verified_at TIMESTAMP Email verification time
password VARCHAR(255) Hashed password
remember_token VARCHAR(100) Remember me token
created_at TIMESTAMP Registration time
updated_at TIMESTAMP Last update time

2. Sessions Table:

Stores user session data for logged-in users.

3. Password Reset Tokens Table:

Stores tokens for password reset requests.

📚 What is Semantic HTML?

Semantic HTML uses tags that clearly describe their meaning to both the browser and the developer.

Benefits:

  • Improves accessibility for screen readers
  • Better SEO (Search Engine Optimization)
  • Easier to maintain code
  • Clearer structure for developers

Non-Semantic vs Semantic

Non-Semantic Semantic
<div id="header"> <header>
<div id="nav"> <nav>
<div id="footer"> <footer>

🏗️ Semantic HTML Structure

<header> - Top section (logo, navigation)
<nav> - Navigation links
<main> - Main content area
<article> - Independent content
<section> - Thematic grouping
<aside> - Sidebar content
<footer> - Bottom section

Key Semantic Elements

1. <header>

Contains introductory content, typically logo, site title, and navigation.

<header> <h1>My Website</h1> <nav> <a href="/">Home</a> <a href="/about">About</a> <a href="/contact">Contact</a> </nav> </header>

2. <nav>

Contains navigation links.

<nav> <ul> <li><a href="/">Home</a></li> <li><a href="/blog">Blog</a></li> <li><a href="/services">Services</a></li> </ul> </nav>

3. <main>

The dominant content of the page. Only one per page.

4. <article>

Self-contained, independent content (blog post, news article).

<article> <h2>Article Title</h2> <p>Article content...</p> </article>

5. <section>

Thematic grouping of content.

6. <aside>

Side content, related to main content (sidebar, callout boxes).

7. <footer>

Footer information (copyright, contact, links).

🎵 Embedding Multimedia

Audio Element

<audio controls> <source src="audio.mp3" type="audio/mpeg"> <source src="audio.ogg" type="audio/ogg"> Your browser does not support the audio element. </audio>

Attributes:

  • controls - Shows play/pause buttons
  • autoplay - Starts automatically
  • loop - Repeats continuously
  • muted - Starts muted

Video Element

<video width="640" height="360" controls> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> Your browser does not support the video tag. </video>

Embedding YouTube Videos

<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen> </iframe>

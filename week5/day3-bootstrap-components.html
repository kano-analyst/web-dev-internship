📐 Spacing Utilities

Bootstrap provides utility classes for controlling spacing (margin and padding):

Class Property Size Example
m-3 Margin all sides 1rem (16px) <div class="m-3">
mt-4 Margin top 1.5rem (24px) <div class="mt-4">
mb-5 Margin bottom 3rem (48px) <div class="mb-5">
p-3 Padding all sides 1rem (16px) <div class="p-3">
px-4 Padding left & right 1.5rem (24px) <div class="px-4">
py-2 Padding top & bottom 0.5rem (8px) <div class="py-2">

📏 Spacing Scale:

  • 0 = 0
  • 1 = 0.25rem (4px)
  • 2 = 0.5rem (8px)
  • 3 = 1rem (16px)
  • 4 = 1.5rem (24px)
  • 5 = 3rem (48px)

Directions: t=top, b=bottom, l=left, r=right, x=horizontal, y=vertical

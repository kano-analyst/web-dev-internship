📐 Understanding the Bootstrap Grid System

Bootstrap Grid System is a powerful 12-column layout system that helps create responsive, flexible layouts.

Key Concepts

  • Container: Wraps grid content (.container or .container-fluid)
  • Row: Horizontal group of columns (.row)
  • Column: Content blocks (.col-*)
  • 12-Column System: Each row divided into 12 equal parts

Grid Structure

<div class="container"> <div class="row"> <div class="col">Column 1</div> <div class="col">Column 2</div> <div class="col">Column 3</div> </div> </div>

📱 Responsive Breakpoints

Breakpoint Class Infix Screen Width
Extra Small col- < 576px (phones)
Small col-sm- ≥ 576px (landscape phones)
Medium col-md- ≥ 768px (tablets)
Large col-lg- ≥ 992px (desktops)
Extra Large col-xl- ≥ 1200px (large desktops)
Extra Extra Large col-xxl- ≥ 1400px (larger desktops)

📊 2-Column Layout

Equal Width Columns

<div class="container"> <div class="row"> <div class="col"> Column 1 - Equal Width </div> <div class="col"> Column 2 - Equal Width </div> </div> </div>

Fixed Width Columns (6/6 Split)

<div class="container"> <div class="row"> <div class="col-6"> Column 1 - 50% Width </div> <div class="col-6"> Column 2 - 50% Width </div> </div> </div>

Different Width Columns (8/4 Split)

<div class="container"> <div class="row"> <div class="col-8"> Main Content - 66.67% Width </div> <div class="col-4"> Sidebar - 33.33% Width </div> </div> </div>

Responsive 2-Column Layout

<div class="container"> <div class="row"> <div class="col-md-6"> Stacks on mobile, side-by-side on tablets+ </div> <div class="col-md-6"> Stacks on mobile, side-by-side on tablets+ </div> </div> </div>

📊 3-Column Layout

Equal Width Columns

<div class="container"> <div class="row"> <div class="col">Column 1</div> <div class="col">Column 2</div> <div class="col">Column 3</div> </div> </div>

Fixed Width (4/4/4 Split)

<div class="container"> <div class="row"> <div class="col-4">Column 1 - 33.33%</div> <div class="col-4">Column 2 - 33.33%</div> <div class="col-4">Column 3 - 33.33%</div> </div> </div>

Responsive 3-Column Layout

<div class="container"> <div class="row"> <div class="col-md-4"> <!-- Stacks on mobile, 3 columns on tablets+ --> Column 1 </div> <div class="col-md-4"> Column 2 </div> <div class="col-md-4"> Column 3 </div> </div> </div>

🔍 Why Form Validation?

Form validation ensures users enter correct data before submitting. This improves user experience and data quality by catching errors before they reach the server.

✅ Common Validation Rules

  • Required fields: Field cannot be empty
  • Email format: Must contain @ and domain
  • Password length: Minimum 8 characters
  • Number validation: Must be a number
  • Phone format: Correct phone number pattern

🔐 Basic Validation Examples

1. Check if Field is Empty

function validateName() { let name = document.getElementById("name").value; if (name === "" || name === null) { alert("Name is required!"); return false; } return true; }

2. Email Validation

function validateEmail() { let email = document.getElementById("email").value; // Check if email contains @ and . if (!email.includes("@") || !email.includes(".")) { alert("Please enter a valid email!"); return false; } return true; } // Better email validation with regex function isValidEmail(email) { let emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/; return emailPattern.test(email); }

3. Password Length Validation

function validatePassword() { let password = document.getElementById("password").value; if (password.length < 8) { alert("Password must be at least 8 characters!"); return false; } return true; }

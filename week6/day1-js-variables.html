  • Work with strings, numbers, and booleans
  • Create and manipulate arrays

📝 What is JavaScript?

JavaScript is a programming language that makes websites interactive. It runs in the browser and can respond to user actions.

🔤 Variables: Storing Data

Variables are containers for storing data values.

Three Ways to Declare Variables

// var - old way (function-scoped) var name = "John"; // let - modern way (block-scoped, can be reassigned) let age = 25; age = 26; // Can change // const - modern way (block-scoped, cannot be reassigned) const country = "Nigeria"; // country = "USA"; // Error! Cannot reassign const

When to Use Each?

  • const: Use by default (values that won't change)
  • let: Use when value will change
  • var: Avoid in modern JavaScript

📊 Data Types

1. String (Text)

let firstName = "Ahmad"; let lastName = 'Garba'; let fullName = "Ahmad Tijjani"; // String concatenation let greeting = "Hello, " + firstName + "!"; console.log(greeting); // Hello, Ahmad! // Template literals (modern way) let message = `Welcome ${firstName} ${lastName}`; console.log(message); // Welcome Ahmad Garba

2. Number

let age = 25; let price = 99.99; let temperature = -5; // Math operations let sum = 10 + 5; // 15 let difference = 20 - 8; // 12 let product = 4 * 3; // 12 let quotient = 15 / 3; // 5 let remainder = 10 % 3; // 1 (modulus)

3. Boolean (True/False)

let isStudent = true; let hasGraduated = false; let isLoggedIn = true; console.log(isStudent); // true

4. Array (List of Values)

// Creating arrays let fruits = ["Apple", "Banana", "Orange"]; let numbers = [1, 2, 3, 4, 5]; let mixed = ["text", 42, true]; // Accessing array elements (index starts at 0) console.log(fruits[0]); // Apple console.log(fruits[1]); // Banana console.log(fruits[2]); // Orange // Array length console.log(fruits.length); // 3 // Adding elements fruits.push("Mango"); // Add to end console.log(fruits); // ["Apple", "Banana", "Orange", "Mango"] // Removing elements fruits.pop(); // Remove last element console.log(fruits); // ["Apple", "Banana", "Orange"]

💻 Console.log() - Printing Output

// Print to browser console console.log("Hello, World!"); // Print variables let name = "Sarah"; console.log(name); // Print multiple values console.log("Name:", name, "Age:", 23);

📂 Important Folders Explained

Folder Purpose When to Use
app/Http/Controllers Store all controllers Every time you create logic
app/Models Eloquent models for database For each database table
resources/views Blade template files For all HTML pages
routes/web.php Define web routes Map URLs to controllers
database/migrations Database structure Creating/modifying tables
public/ Public files (CSS, JS, images) Static assets
config/ Configuration files App settings

⚙️ The .env File (Environment Configuration)

.env file contains environment-specific settings like database credentials, app key, debug mode, etc. This file is NOT committed to version control for security.

Open .env File:

Located at project root: C:\xampp\htdocs\student-management\.env

Important .env Settings:

# Application APP_NAME="Student Management System" APP_ENV=local # local, production, testing APP_KEY=base64:xxx # Auto-generated, don't change APP_DEBUG=true # Show errors (true for development) APP_URL=http://localhost:8000 # Database Connection DB_CONNECTION=mysql DB_HOST=127.0.0.1 DB_PORT=3306 DB_DATABASE=student_management # Your database name DB_USERNAME=root # MySQL username DB_PASSWORD= # MySQL password (empty for XAMPP) # Mail (for later) MAIL_MAILER=smtp MAIL_HOST=smtp.gmail.com MAIL_PORT=587

🗄️ Configure Database Connection

Step 1: Create Database in phpMyAdmin

  1. Start Apache and MySQL in XAMPP
  2. Open phpMyAdmin: http://localhost/phpmyadmin
  3. Click "New" in left sidebar
  4. Database name: student_management
  5. Collation: utf8mb4_general_ci
  6. Click "Create"

Step 2: Update .env File

# Open .env file and update: DB_CONNECTION=mysql DB_HOST=127.0.0.1 DB_PORT=3306 DB_DATABASE=student_management # ← Your database name DB_USERNAME=root DB_PASSWORD= # Leave empty for XAMPP

Step 3: Test Database Connection

# In terminal/PowerShell (in project directory): php artisan migrate # If successful, you should see: # Migration table created successfully. # Migrated: 2014_10_12_000000_create_users_table # etc...

📝 Configuration Files Overview

config/app.php - Application Settings

return [ 'name' => env('APP_NAME', 'Laravel'), // App name 'env' => env('APP_ENV', 'production'), // Environment 'debug' => env('APP_DEBUG', false), // Debug mode 'url' => env('APP_URL', 'http://localhost'), 'timezone' => 'UTC', // Can change to 'Africa/Lagos' 'locale' => 'en', // Default language ];

config/database.php - Database Settings

'default' => env('DB_CONNECTION', 'mysql'), 'connections' => [ 'mysql' => [ 'driver' => 'mysql', 'host' => env('DB_HOST', '127.0.0.1'), 'port' => env('DB_PORT', '3306'), 'database' => env('DB_DATABASE', 'forge'), 'username' => env('DB_USERNAME', 'forge'), 'password' => env('DB_PASSWORD', ''), ], ],

🔑 Generate Application Key

Laravel requires an application key for encryption. This is auto-generated, but if needed:

php artisan key:generate # Output: # Application key set successfully. # This updates APP_KEY in .env file

🧹 Clear Cache Commands

Useful when configuration isn't updating:

# Clear configuration cache php artisan config:clear # Clear application cache php artisan cache:clear # Clear route cache php artisan route:clear # Clear view cache php artisan view:clear # Clear all caches at once php artisan optimize:clear

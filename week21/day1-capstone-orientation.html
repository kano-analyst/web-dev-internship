🏆 What is a Capstone Project?

A capstone project is your opportunity to demonstrate everything you've learned throughout this bootcamp. It's a comprehensive, real-world web application that showcases your skills in:

  • Frontend Development (HTML, CSS, Bootstrap, JavaScript)
  • Backend Development (PHP, Laravel)
  • Database Design (MySQL, Eloquent ORM)
  • Authentication & Authorization (Laravel Breeze)
  • API Development (Laravel Sanctum)
  • Deployment & Version Control (Git, cPanel/Laravel Forge)

📋 Grading Rubric (100 Points Total)

Category Points Description
Project Proposal 10 Clear problem statement, scope, and requirements
Database Design 15 Well-structured schema, relationships, migrations
Backend Implementation 20 Functional CRUD, authentication, validation
Frontend Design 15 Responsive, user-friendly interface
Features & Functionality 15 Complete features, API integration, file uploads
Testing & Debugging 5 Bug-free, tested application
Documentation 5 Technical docs, user manual, README
Deployment 5 Live, accessible application
Presentation 10 Professional, clear demonstration

💡 Project Ideas & Examples

Recommended Project Categories

1. E-Commerce & Marketplace

  • Online Store with product catalog, cart, and checkout
  • Auction platform with bidding system
  • Marketplace connecting buyers and sellers

2. Management Systems

  • Student Management System (grades, attendance, courses)
  • Hospital Management System (appointments, patient records)
  • Library Management System (books, borrowing, returns)
  • Inventory Management System (stock tracking, orders)
  • Hotel Booking System (reservations, rooms, payments)

3. Social & Communication

  • Social Media Platform (posts, comments, likes, followers)
  • Discussion Forum with categories and threads
  • Event Management Platform (registration, tickets)

4. Learning & Education

  • Online Learning Platform (courses, videos, quizzes)
  • Quiz/Examination System with timer and grading
  • Assignment Submission & Grading Portal

5. Business & Finance

  • Expense Tracker with reports and charts
  • Invoice Management System
  • Real Estate Listing Platform
  • Job Board with applications and resume uploads
💡 Tip: Choose a project that solves a real problem you've experienced or observed in your community!

👥 Team Formation Guidelines

Team Structure (3-4 Members Recommended)

Suggested Roles:

  1. Team Lead / Project Manager:
    • Coordinates team meetings and tasks
    • Manages GitHub repository and version control
    • Ensures deadlines are met
  2. Backend Developer:
    • Database design and migrations
    • Laravel controllers and models
    • API development and authentication
  3. Frontend Developer:
    • UI/UX design and Blade templates
    • Responsive design with Bootstrap
    • JavaScript interactivity
  4. Tester / Documentation Lead:
    • Testing and quality assurance
    • Writing documentation and user manuals
    • Deployment assistance

Note: In 3-member teams, members can combine roles (e.g., Frontend + Testing).

📝 Project Selection Criteria

Your project MUST include:

  • ✅ User authentication (login, registration, logout)
  • ✅ Complete CRUD operations (Create, Read, Update, Delete)
  • ✅ Database with at least 4 related tables
  • ✅ Form validation and error handling
  • ✅ Responsive design (mobile and desktop)
  • ✅ At least one file upload feature
  • ✅ Search and filtering functionality

Bonus Features (Optional but Impressive):

  • 🌟 RESTful API with Sanctum authentication
  • 🌟 Email notifications (welcome email, notifications)
  • 🌟 Pagination for large datasets
  • 🌟 Role-based access control (Admin/User)
  • 🌟 Data visualization (charts/graphs)
  • 🌟 Payment integration (optional)

✏️ Today's Tasks

Task 1: Form Your Team (30 minutes)

  1. Discuss interests and strengths with classmates
  2. Form a team of 3-4 members
  3. Assign preliminary roles
  4. Exchange contact information (WhatsApp, email)

Task 2: Brainstorm Project Ideas (45 minutes)

  1. Each team member proposes 2-3 project ideas
  2. Discuss feasibility and required features
  3. Vote on top 3 ideas
  4. Create a shortlist for instructor review

Task 3: Preliminary Research (30 minutes)

  1. Research similar projects online
  2. Identify key features and user flows
  3. List potential challenges
  4. Prepare questions for instructor

Task 4: Get Approval (15 minutes)

  1. Present your top idea to the instructor
  2. Discuss scope and requirements
  3. Get feedback and approval
  4. Finalize project selection

📦 Deliverables

Submit by end of class:

  1. Team Formation Document:
    • Team name
    • Member names and roles
    • Contact information
  2. Project Selection Form:
    • Project title
    • Brief description (2-3 sentences)
    • Target users
    • Key features (list 5-7 main features)
  3. Instructor approval signature
🎯 Success Tips:
  • Choose a project you're passionate about
  • Start with a clear scope—avoid feature creep
  • Communicate regularly with your team
  • Don't be afraid to ask for help
  • Use version control from day one

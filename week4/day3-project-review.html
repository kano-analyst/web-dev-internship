🚀 Deploying to GitHub Pages

GitHub Pages is a free hosting service for static websites directly from your GitHub repository.

Step 1: Prepare Your Repository

# Make sure all changes are committed git status # If there are changes, commit them git add . git commit -m "Final version ready for deployment" git push origin main

Step 2: Enable GitHub Pages

  1. Go to your GitHub repository
  2. Click Settings tab
  3. Scroll down to Pages section (left sidebar)
  4. Under Source, select main branch
  5. Keep / (root) selected
  6. Click Save

🎉 Your site will be published at:

https://yourusername.github.io/portfolio/

It may take 1-2 minutes to go live!

Step 3: Verify Deployment

  1. Wait 1-2 minutes
  2. Visit your GitHub Pages URL
  3. Test all functionality
  4. Check on mobile device if possible

Troubleshooting Common Issues

Problem Solution
Images not loading Check image paths are relative: images/profile.jpg
CSS not applying Verify CSS link path: <link rel="stylesheet" href="style.css">
404 error Make sure index.html is in root folder
Old version showing Clear browser cache (Ctrl+F5)

🐛 Bug Fixing & Optimization

Common Issues to Check

1. Mobile Menu Not Working

// Check if JavaScript is included in HTML // Verify hamburger click event const hamburger = document.querySelector('.hamburger'); const navMenu = document.querySelector('.nav-menu'); hamburger.addEventListener('click', () => { hamburger.classList.toggle('active'); navMenu.classList.toggle('active'); });

2. Images Not Displaying

CORRECT: <img src="images/profile.jpg" alt="Profile"> WRONG: <img src="/images/profile.jpg" alt="Profile"> <img src="C:/Users/images/profile.jpg" alt="Profile">

3. Layout Breaking on Mobile

/* Ensure viewport meta tag is present */ <meta name="viewport" content="width=device-width, initial-scale=1.0"> /* Check media queries */ @media (max-width: 768px) { .about-content { grid-template-columns: 1fr; /* Stack on mobile */ } }

Code Optimization Tips

  • Compress images: Use TinyPNG or similar tools
  • Minify CSS: Remove unnecessary spaces (for production)
  • Remove unused code: Clean up commented-out sections
  • Optimize fonts: Load only needed font weights
  • Add alt text: All images should have descriptive alt text

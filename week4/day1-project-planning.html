🚀 Final Project Overview

Project: Personal Portfolio Website

Build a professional portfolio website to showcase your skills, projects, and contact information.

Required Pages/Sections

  1. Home/Hero Section: Eye-catching introduction with your name and tagline
  2. About Section: Your background, education, and interests
  3. Skills Section: Technical skills with visual elements
  4. Projects Section: Showcase 3-4 projects you've built
  5. Contact Section: Contact form and social media links

Technical Requirements

  • ✅ Semantic HTML5 structure
  • ✅ Custom CSS styling (no frameworks required)
  • ✅ Fully responsive design (mobile, tablet, desktop)
  • ✅ Navigation menu
  • ✅ Interactive elements (hover effects, transitions)
  • ✅ Form validation
  • ✅ Proper Git version control
  • ✅ Deployed on GitHub Pages

📐 What is Wireframing?

Wireframe: A visual blueprint showing the structure and layout of a website before coding.

Why Wireframe?

  • Plan layout: Decide where elements go before coding
  • Save time: Catch issues early in design phase
  • Focus on structure: Without worrying about colors/fonts
  • Client communication: Show ideas before building
  • User experience: Test navigation flow

Wireframe Types

  • Low-fidelity: Simple sketches, boxes and lines (we'll use this)
  • Mid-fidelity: More detail, basic styling
  • High-fidelity: Detailed mockups with colors and images

Wireframing Tools

  • 📝 Paper and pen (fastest for brainstorming)
  • 🖼️ Figma (free, professional)
  • 🎨 Balsamiq (specialized for wireframes)
  • ✏️ Excalidraw (simple, web-based)
  • 📱 Whimsical

💻 Main Activity: Create Your Wireframe

Task: Design Your Portfolio Wireframes

Create wireframes for your portfolio on paper or using a digital tool

Steps to Complete

  1. Choose Your Tool:
    • Paper and pen (recommended for beginners)
    • Figma (free account at figma.com)
    • Excalidraw (excalidraw.com)
  2. Create Desktop Wireframe:
    • Draw header with navigation
    • Hero section with name and CTA
    • About section with photo and text
    • Skills section with skill cards
    • Projects section (grid layout)
    • Contact section with form
    • Footer
  3. Create Mobile Wireframe:
    • Hamburger menu navigation
    • Stacked sections
    • Single column layout
    • Optimized for touch
  4. Gather Content:
    • Write your bio
    • List your skills
    • Describe 3-4 projects
    • Prepare images (or use placeholders)
  5. Set Up Project:
    • Create portfolio folder
    • Initialize Git repository
    • Create file structure
    • Write README.md
    • Create GitHub repository
    • Push initial commit

🎨 Design Tips

  • Modern Purple: #512da8, #673ab7, #9c27b0
  • Tech Green: #1b5e20, #4caf50, #81c784
  • Elegant Gray: #424242, #757575, #e0e0e0
  • Creative Orange: #e65100, #ff6f00, #ffab91

Typography Suggestions

  • Headings: Montserrat, Raleway, Poppins
  • Body Text: Open Sans, Roboto, Lato
  • Code: Fira Code, Source Code Pro, Monaco

UX Best Practices

  • ✅ Clear navigation visible at all times
  • ✅ Strong visual hierarchy
  • ✅ Plenty of white space
  • ✅ Fast loading times
  • ✅ Accessible to all users
  • ✅ Mobile-friendly from the start
  • ✅ Clear call-to-action buttons

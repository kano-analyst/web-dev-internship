📦 PHP Arrays

Arrays are variables that can store multiple values. PHP supports indexed arrays (with numeric keys) and associative arrays (with named keys).

1. Indexed Arrays

<?php // Creating indexed array $fruits = array("Apple", "Banana", "Orange"); // Or using short syntax $colors = ["Red", "Green", "Blue"]; // Accessing array elements (index starts at 0) echo $fruits[0]; // Apple echo $fruits[1]; // Banana echo $fruits[2]; // Orange // Array length echo count($fruits); // 3 // Adding elements $fruits[] = "Mango"; // Add to end $colors[3] = "Yellow"; // Add at specific index ?>

2. Associative Arrays

<?php // Array with named keys $student = array( "name" => "Ahmad Garba", "age" => 25, "city" => "Kano", "course" => "Web Development" ); // Or using short syntax $product = [ "name" => "Laptop", "price" => 50000, "brand" => "HP" ]; // Accessing values echo $student["name"]; // Ahmad Garba echo $product["price"]; // 50000 // Adding new key-value pair $student["email"] = "ahmad@example.com"; ?>

3. Multidimensional Arrays

<?php $students = [ ["name" => "Ahmad", "age" => 25], ["name" => "Fatima", "age" => 23], ["name" => "Ibrahim", "age" => 27] ]; // Access nested arrays echo $students[0]["name"]; // Ahmad echo $students[1]["age"]; // 23 ?>

🔀 Conditional Statements

if Statement

<?php $age = 20; if ($age >= 18) { echo "You are an adult"; } ?>

if...else Statement

<?php $score = 75; if ($score >= 50) { echo "You passed!"; } else { echo "You failed."; } ?>

if...elseif...else Statement

<?php $grade = 85; if ($grade >= 90) { echo "Grade: A"; } elseif ($grade >= 80) { echo "Grade: B"; } elseif ($grade >= 70) { echo "Grade: C"; } elseif ($grade >= 60) { echo "Grade: D"; } else { echo "Grade: F"; } ?>

Comparison Operators

Operator Meaning Example
==Equal to$a == $b
===Identical (value & type)$a === $b
!=Not equal$a != $b
<Less than$a < $b
>Greater than$a > $b
<=Less than or equal$a <= $b
>=Greater than or equal$a >= $b

Logical Operators

<?php $age = 25; $hasLicense = true; // AND operator if ($age >= 18 && $hasLicense) { echo "You can drive"; } // OR operator if ($age < 18 || !$hasLicense) { echo "You cannot drive"; } // NOT operator if (!$hasLicense) { echo "No license"; } ?>

🔁 Loops

1. for Loop

<?php // Print numbers 1 to 10 for ($i = 1; $i <= 10; $i++) { echo $i . " "; } // Loop through indexed array $fruits = ["Apple", "Banana", "Orange", "Mango"]; for ($i = 0; $i < count($fruits); $i++) { echo $fruits[$i] . "<br>"; } ?>

2. while Loop

<?php $count = 1; while ($count <= 5) { echo "Count: " . $count . "<br>"; $count++; } ?>

3. foreach Loop (for Arrays)

<?php // Loop through indexed array $colors = ["Red", "Green", "Blue"]; foreach ($colors as $color) { echo $color . "<br>"; } // Loop through associative array $student = [ "name" => "Ahmad", "age" => 25, "city" => "Kano" ]; foreach ($student as $key => $value) { echo $key . ": " . $value . "<br>"; } ?>

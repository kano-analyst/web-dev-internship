🌐 What is PHP?

PHP (Hypertext Preprocessor) is a server-side scripting language used to create dynamic web pages. Unlike HTML/CSS/JavaScript which run in the browser, PHP runs on the server and generates HTML that is sent to the browser.

Why Learn PHP?

  • ✅ Powers 77% of websites (WordPress, Facebook, Wikipedia)
  • ✅ Easy to learn for beginners
  • ✅ Connects to databases (MySQL, PostgreSQL)
  • ✅ Free and open-source
  • ✅ Large community and resources

💻 Installing XAMPP

Step 1: Download XAMPP

  1. Visit apachefriends.org
  2. Download XAMPP for your operating system (Windows/Mac/Linux)
  3. Choose the latest PHP version (PHP 8.x)

Step 2: Install XAMPP

  1. Run the installer
  2. Select components: Apache, MySQL, PHP, phpMyAdmin
  3. Choose installation directory (default: C:\xampp)
  4. Complete installation

Step 3: Start Apache Server

  1. Open XAMPP Control Panel
  2. Click "Start" next to Apache
  3. Apache should turn green
  4. Open browser and go to: http://localhost
  5. You should see XAMPP welcome page

📂 Project Folder Structure

🔤 PHP Syntax Basics

PHP Tags

<?php // PHP code goes here echo "Hello, World!"; ?>

Embedding PHP in HTML

<!DOCTYPE html> <html> <head> <title>My First PHP Page</title> </head> <body> <h1>Welcome to PHP</h1> <?php echo "<p>This paragraph was generated by PHP!</p>"; echo "<p>Current date: " . date("Y-m-d") . "</p>"; ?> </body> </html>

📝 PHP Variables

Variable Declaration

<?php // Variables start with $ sign $name = "Ahmad"; $age = 25; $price = 99.99; $isStudent = true; // Display variables echo "Name: " . $name; echo "<br>"; echo "Age: " . $age; ?>

Variable Rules

  • Must start with $ sign
  • Variable name must start with letter or underscore
  • Can only contain letters, numbers, and underscores
  • Case-sensitive ($name ≠ $Name)

🔢 PHP Data Types

Data Type Description Example
String Text data $name = "John";
Integer Whole numbers $age = 25;
Float Decimal numbers $price = 99.99;
Boolean True or False $isActive = true;
Array Multiple values $colors = ["red", "blue"];

🖨️ Echo and Print

<?php // Using echo echo "Hello, World!"; echo "<br>"; // Multiple values with echo echo "Name: ", $name, " Age: ", $age; // Using print print "Hello again!"; // Concatenation with dot (.) echo "My name is " . $name . " and I am " . $age . " years old."; ?>

🐛 Common Errors & Solutions

Error Solution
Parse error: syntax error Check for missing semicolons (;) at end of statements
Undefined variable Make sure variable is declared before using it
Page shows PHP code Apache not running, or file doesn't have .php extension
localhost not working Start Apache in XAMPP Control Panel

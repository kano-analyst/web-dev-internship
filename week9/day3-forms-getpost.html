📨 HTTP Methods: GET vs POST

Feature GET POST
Visibility Data visible in URL Data hidden in request body
Security Less secure More secure
Data Size Limited (~2000 characters) Unlimited
Bookmarking Can be bookmarked Cannot be bookmarked
Use Case Search queries, filters Login forms, file uploads

🔤 GET Method

HTML Form with GET

<!-- search_form.html --> <!DOCTYPE html> <html> <head> <title>Search Form</title> </head> <body> <h2>Search Products</h2> <form action="search.php" method="GET"> <label>Product Name:</label> <input type="text" name="product" required> <br><br> <label>Category:</label> <select name="category"> <option value="electronics">Electronics</option> <option value="clothing">Clothing</option> <option value="books">Books</option> </select> <br><br> <button type="submit">Search</button> </form> </body> </html>

Processing GET Data in PHP

<?php // search.php if (isset($_GET['product']) && isset($_GET['category'])) { $product = $_GET['product']; $category = $_GET['category']; echo "<h2>Search Results</h2>"; echo "<p>Searching for: <strong>" . $product . "</strong></p>"; echo "<p>Category: <strong>" . $category . "</strong></p>"; // URL will look like: search.php?product=laptop&category=electronics } ?>

Processing POST Data in PHP

<?php // login.php if ($_SERVER["REQUEST_METHOD"] == "POST") { $username = $_POST['username']; $password = $_POST['password']; // Simple validation if ($username == "admin" && $password == "password123") { echo "<h2>Welcome, " . $username . "!</h2>"; echo "<p>Login successful.</p>"; } else { echo "<h2>Login Failed</h2>"; echo "<p>Invalid username or password.</p>"; } } ?>

🛡️ Input Validation & Security

Basic Validation

<?php if ($_SERVER["REQUEST_METHOD"] == "POST") { $email = $_POST['email']; $age = $_POST['age']; // Check if email is empty if (empty($email)) { echo "Email is required!"; } // Validate email format elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) { echo "Invalid email format!"; } // Check if age is numeric elseif (!is_numeric($age)) { echo "Age must be a number!"; } // Check age range elseif ($age < 18 || $age > 100) { echo "Age must be between 18 and 100!"; } else { echo "Form submitted successfully!"; } } ?>

Sanitizing Input

<?php // Remove HTML tags and special characters $name = htmlspecialchars($_POST['name']); // Remove whitespace $username = trim($_POST['username']); // Convert to lowercase $email = strtolower($_POST['email']); // Strip tags $comment = strip_tags($_POST['comment']); ?>

🔒 Security Best Practices

  • ✓ Always use POST for sensitive data (passwords, personal info)
  • ✓ Validate all user inputs on the server side
  • ✓ Use htmlspecialchars() to prevent XSS attacks
  • ✓ Never trust user input - always sanitize
  • ✓ Check if form is submitted using $_SERVER["REQUEST_METHOD"]

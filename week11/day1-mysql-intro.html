🗄️ What is a Database?

Database: An organized collection of data stored electronically. Think of it like an Excel file, but much more powerful!

  • Table: Like a spreadsheet (e.g., students table)
  • Row: A single record (e.g., one student)
  • Column: A field/attribute (e.g., name, email)
  • Primary Key: Unique identifier for each row (e.g., id)

📊 Database vs File Storage

Feature Files (Week 10) Database (Week 11)
Search Slow, read entire file Fast, indexed search
Update Rewrite entire file Update specific record
Structure Unstructured text Structured tables
Multiple Users Difficult Handles concurrency
Security Basic Advanced permissions

  4. Click "Create"

Using SQL Query:

-- Create database CREATE DATABASE school_db; -- Select the database to use USE school_db;

📋 Creating Tables

Students Table:

CREATE TABLE students ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100) NOT NULL, email VARCHAR(100) UNIQUE NOT NULL, age INT NOT NULL, course VARCHAR(50), created_at DATETIME DEFAULT CURRENT_TIMESTAMP );
Table Structure Explained:
  • id INT AUTO_INCREMENT PRIMARY KEY - Unique ID, automatically increases
  • VARCHAR(100) NOT NULL - Text field, cannot be empty
  • UNIQUE - Value must be unique (no duplicates)
  • DEFAULT CURRENT_TIMESTAMP - Automatically set current date/time

More Example Tables:

-- Products table CREATE TABLE products ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(200) NOT NULL, description TEXT, price DECIMAL(10, 2) NOT NULL, stock INT DEFAULT 0, created_at DATETIME DEFAULT CURRENT_TIMESTAMP ); -- Blog posts table CREATE TABLE posts ( id INT AUTO_INCREMENT PRIMARY KEY, title VARCHAR(200) NOT NULL, content TEXT NOT NULL, author VARCHAR(100), views INT DEFAULT 0, published BOOLEAN DEFAULT 0, created_at DATETIME DEFAULT CURRENT_TIMESTAMP );

➕ Inserting Data (INSERT)

Insert Single Record:

-- Insert one student INSERT INTO students (name, email, age, course) VALUES ('Ahmad Ibrahim', 'ahmad@email.com', 20, 'Web Development'); -- Insert with fewer fields (optional fields can be skipped) INSERT INTO students (name, email, age) VALUES ('Fatima Yusuf', 'fatima@email.com', 22);

Insert Multiple Records:

📖 Selecting Data (SELECT)

Select All Records:

-- Get all students SELECT * FROM students;

Select Specific Columns:

-- Get only names and emails SELECT name, email FROM students;

Select with WHERE Clause:

-- Get students in Web Development course SELECT * FROM students WHERE course = 'Web Development'; -- Get students older than 20 SELECT * FROM students WHERE age > 20; -- Get specific student by email SELECT * FROM students WHERE email = 'ahmad@email.com';

Select with ORDER BY:

-- Order by name (A-Z) SELECT * FROM students ORDER BY name ASC; -- Order by age (oldest first) SELECT * FROM students ORDER BY age DESC;

Select with LIMIT:

-- Get first 5 students SELECT * FROM students LIMIT 5; -- Get students 6-10 SELECT * FROM students LIMIT 5 OFFSET 5;

💻 Complete Example: School Database

Query examples -- Get all students SELECT * FROM students; -- Get Web Development students only SELECT * FROM students WHERE course = 'Web Development'; -- Get students with grade A SELECT * FROM students WHERE grade = 'A'; -- Count students per course SELECT course, COUNT(*) as total FROM students GROUP BY course; -- Get youngest to oldest SELECT name, age FROM students ORDER BY age ASC;

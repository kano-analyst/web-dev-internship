🔌 MySQLi Connection (Procedural)

<?php // Database credentials $host = "localhost"; $username = "root"; $password = ""; $database = "school_db"; // Create connection $conn = mysqli_connect($host, $username, $password, $database); // Check connection if (!$conn) { die("Connection failed: " . mysqli_connect_error()); } echo "Connected successfully!"; // Close connection when done mysqli_close($conn); ?>

📁 Database Configuration File

<?php // config.php - Save database connection settings $host = "localhost"; $username = "root"; $password = ""; $database = "school_db"; // Create connection $conn = mysqli_connect($host, $username, $password, $database); // Check connection if (!$conn) { die("Connection failed: " . mysqli_connect_error()); } // Optional: Set charset to UTF-8 mysqli_set_charset($conn, "utf8mb4"); ?>

📥 Inserting Data from PHP

Method 1: Simple Query (Not Secure)

<?php require_once 'config.php'; $name = "Ahmad Ibrahim"; $email = "ahmad@email.com"; $age = 20; $course = "Web Development"; // Create SQL query $sql = "INSERT INTO students (name, email, age, course) VALUES ('$name', '$email', $age, '$course')"; // Execute query if (mysqli_query($conn, $sql)) { echo "New student added successfully!"; } else { echo "Error: " . mysqli_error($conn); } mysqli_close($conn); ?>

Method 2: Prepared Statements (Secure ✅)

<?php require_once 'config.php'; $name = "Ahmad Ibrahim"; $email = "ahmad@email.com"; $age = 20; $course = "Web Development"; // Prepare statement $stmt = mysqli_prepare($conn, "INSERT INTO students (name, email, age, course) VALUES (?, ?, ?, ?)"); // Bind parameters (s = string, i = integer) mysqli_stmt_bind_param($stmt, "ssis", $name, $email, $age, $course); // Execute if (mysqli_stmt_execute($stmt)) { echo "New student added successfully!"; echo "New ID: " . mysqli_insert_id($conn); } else { echo "Error: " . mysqli_error($conn); } mysqli_stmt_close($stmt); mysqli_close($conn); ?>
Parameter Types in bind_param:
  • s - String
  • i - Integer
  • d - Double/Float
  • b - Blob (binary)

📤 Selecting Data from PHP

Fetch All Records:

<?php require_once 'config.php'; $sql = "SELECT * FROM students"; $result = mysqli_query($conn, $sql); if (mysqli_num_rows($result) > 0) { echo "<table border='1'>"; echo "<tr><th>ID</th><th>Name</th><th>Email</th><th>Age</th><th>Course</th></tr>"; // Loop through results while ($row = mysqli_fetch_assoc($result)) { echo "<tr>"; echo "<td>" . $row['id'] . "</td>"; echo "<td>" . $row['name'] . "</td>"; echo "<td>" . $row['email'] . "</td>"; echo "<td>" . $row['age'] . "</td>"; echo "<td>" . $row['course'] . "</td>"; echo "</tr>"; } echo "</table>"; } else { echo "No students found."; } mysqli_close($conn); ?>

✅ Security Best Practices

  • ✓ Always use prepared statements (prevents SQL injection)
  • ✓ Validate all user inputs
  • ✓ Use htmlspecialchars() when displaying data
  • ✓ Never display database errors to users in production
  • ✓ Store database credentials in separate config file
  • ✓ Close database connections when done

🔄 What is CRUD?

CRUD stands for the four basic operations for persistent storage:

  • Create - Add new records (INSERT)
  • Read - View existing records (SELECT)
  • Update - Modify existing records (UPDATE)
  • Delete - Remove records (DELETE)

🔄 UPDATE Query

Basic Syntax:

UPDATE table_name SET column1 = value1, column2 = value2 WHERE condition;

Update Examples:

-- Update one field UPDATE students SET age = 21 WHERE id = 1; -- Update multiple fields UPDATE students SET name = 'Ahmad Ibrahim', age = 21, course = 'Data Science' WHERE id = 1; -- Update based on condition UPDATE students SET grade = 'A' WHERE age >= 21;

Update with PHP:

<?php require_once 'config.php'; $id = 1; $name = "Ahmad Ibrahim Updated"; $email = "ahmad.new@email.com"; $age = 21; $course = "Data Science"; // Prepare UPDATE statement $stmt = mysqli_prepare($conn, "UPDATE students SET name = ?, email = ?, age = ?, course = ? WHERE id = ?"); mysqli_stmt_bind_param($stmt, "ssisi", $name, $email, $age, $course, $id); if (mysqli_stmt_execute($stmt)) { echo "Student updated successfully!"; } else { echo "Error: " . mysqli_error($conn); } mysqli_stmt_close($stmt); mysqli_close($conn); ?>

❌ DELETE Query

Basic Syntax:

DELETE FROM table_name WHERE condition;

Delete Examples:

-- Delete specific record DELETE FROM students WHERE id = 1; -- Delete based on condition DELETE FROM students WHERE age < 18; -- ⚠️ Delete all records (BE CAREFUL!) DELETE FROM students;

Delete with PHP:

<?php require_once 'config.php'; $id = 5; // Prepare DELETE statement $stmt = mysqli_prepare($conn, "DELETE FROM students WHERE id = ?"); mysqli_stmt_bind_param($stmt, "i", $id); if (mysqli_stmt_execute($stmt)) { if (mysqli_stmt_affected_rows($stmt) > 0) { echo "Student deleted successfully!"; } else { echo "No student found with that ID."; } } else { echo "Error: " . mysqli_error($conn); } mysqli_stmt_close($stmt); mysqli_close($conn); ?>

✅ CRUD Best Practices

  • ✓ Always use WHERE clause with UPDATE and DELETE
  • ✓ Confirm before deleting (JavaScript confirm dialog)
  • ✓ Validate data before updating
  • ✓ Check if record exists before operations
  • ✓ Use prepared statements to prevent SQL injection
  • ✓ Display success/error messages to users
  • ✓ Redirect after successful operations

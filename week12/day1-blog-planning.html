📝 Project Overview: Simple Blog System

What We're Building:

A complete blog application where users can create, view, edit, and delete blog posts. This project combines everything you've learned: HTML, CSS, PHP, and MySQL!

✨ Project Features

📰 View Posts

Display all blog posts on homepage with title, excerpt, author, and date

➕ Create Post

Form to add new blog posts with title, content, and author

👁️ View Single Post

Read full blog post with all details

✏️ Edit Post

Update existing blog posts

🗑️ Delete Post

Remove unwanted blog posts

🔍 Search

Find posts by title or content

🗄️ Database Schema

Posts Table Structure:

Column Data Type Description
id INT AUTO_INCREMENT PRIMARY KEY Unique post ID
title VARCHAR(200) NOT NULL Post title
content TEXT NOT NULL Full post content
author VARCHAR(100) NOT NULL Author name
category VARCHAR(50) Post category (optional)
views INT DEFAULT 0 View count
created_at DATETIME DEFAULT CURRENT_TIMESTAMP Creation date/time
updated_at DATETIME ON UPDATE CURRENT_TIMESTAMP Last update date/time

SQL to Create Database and Table:

-- 1. Create database CREATE DATABASE blog_db; USE blog_db; -- 2. Create posts table CREATE TABLE posts ( id INT AUTO_INCREMENT PRIMARY KEY, title VARCHAR(200) NOT NULL, content TEXT NOT NULL, author VARCHAR(100) NOT NULL, category VARCHAR(50), views INT DEFAULT 0, created_at DATETIME DEFAULT CURRENT_TIMESTAMP, updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP ); -- 3. 💻 Setting Up Today

Step 1: Create Database

  1. Open phpMyAdmin
  2. Create database blog_db
  3. Run the SQL above to create posts table
  4. Insert sample data

Step 2: Create Project Folder

  1. In C:\xampp\htdocs\ create folder blog-project
  2. Create subfolders: config, includes, css

Step 3: Database Connection (config/database.php)

<?php // config/database.php // Database configuration define('DB_HOST', 'localhost'); define('DB_USER', 'root'); define('DB_PASS', ''); define('DB_NAME', 'blog_db'); // Create connection $conn = mysqli_connect(DB_HOST, DB_USER, DB_PASS, DB_NAME); // Check connection if (!$conn) { die("Connection failed: " . mysqli_connect_error()); } // Set charset mysqli_set_charset($conn, "utf8mb4"); ?>

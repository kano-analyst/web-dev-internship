🗑️ Delete Post (delete_post.php)

<?php // delete_post.php require_once 'config/database.php'; // Get post ID $post_id = isset($_GET['id']) ? (int)$_GET['id'] : 0; if ($post_id > 0) { // Delete post $stmt = mysqli_prepare($conn, "DELETE FROM posts WHERE id = ?"); mysqli_stmt_bind_param($stmt, "i", $post_id); if (mysqli_stmt_execute($stmt)) { if (mysqli_stmt_affected_rows($stmt) > 0) { $message = "Post deleted successfully!"; } else { $message = "Post not found."; } } else { $message = "Error deleting post."; } mysqli_stmt_close($stmt); } else { $message = "Invalid post ID."; } mysqli_close($conn); // Redirect to homepage with message header("Location: index.php?message=" . urlencode($message)); exit(); ?>

🔒 Security Best Practices Implemented

✅ Security Checklist:

  • ✓ Prepared Statements: All database queries use prepared statements to prevent SQL injection
  • ✓ Input Validation: All user inputs are validated before processing
  • ✓ Output Escaping: Using htmlspecialchars() to prevent XSS attacks
  • ✓ Type Casting: IDs are cast to integers: (int)$_GET['id']
  • ✓ Sanitization: Using trim() to remove extra whitespace
  • ✓ Confirmation: JavaScript confirm() before deleting

  4. Upload Files: Use FTP to upload project files

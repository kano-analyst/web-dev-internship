🔐 CSRF Protection

Security First! Laravel protects against Cross-Site Request Forgery (CSRF) attacks. Every form MUST include @csrf directive.

Basic Form with CSRF:

<!-- resources/views/contact.blade.php --> <form action="/contact" method="POST"> @csrf <label>Name:</label> <input type="text" name="name"> <label>Email:</label> <input type="email" name="email"> <label>Message:</label> <textarea name="message"></textarea> <button type="submit">Send</button> </form>

📝 Handling Form Submission

Route Definition:

<?php // routes/web.php use App\Http\Controllers\ContactController; Route::get('/contact', [ContactController::class, 'show']); Route::post('/contact', [ContactController::class, 'submit']); ?>

Controller with Validation:

<?php // app/Http/Controllers/ContactController.php namespace App\Http\Controllers; use Illuminate\Http\Request; class ContactController extends Controller { public function show() { return view('contact'); } public function submit(Request $request) { // Validate form data $validated = $request->validate([ 'name' => 'required|min:3|max:50', 'email' => 'required|email', 'message' => 'required|min:10|max:500', ]); // Process the data (save to database, send email, etc.) // For now, just redirect with success message return redirect('/contact')->with('success', 'Message sent successfully!'); } } ?>

✅ Validation Rules

Rule Description Example
required Field must not be empty 'name' => 'required'
email Must be valid email format 'email' => 'email'
min:n Minimum length/value 'password' => 'min:8'
max:n Maximum length/value 'name' => 'max:50'
numeric Must be a number 'age' => 'numeric'
alpha Only letters (A-Z, a-z) 'name' => 'alpha'
alpha_num Letters and numbers only 'username' => 'alpha_num'
confirmed Must match _confirmation field 'password' => 'confirmed'
unique:table Value must be unique in table 'email' => 'unique:users'
in:val1,val2 Value must be in list 'role' => 'in:admin,user'

🚨 Displaying Validation Errors

Method 1: Display All Errors

<!-- Show all errors at top of form --> @if($errors->any()) <div style="background: #f8d7da; color: #721c24; padding: 15px; border-radius: 5px; margin-bottom: 20px;"> <strong>Please fix the following errors:</strong> <ul style="margin: 10px 0 0 20px;"> @foreach($errors->all() as $error) <li>{{ $error }}</li> @endforeach </ul> </div> @endif

Method 2: Display Error Per Field

<label>Name:</label> <input type="text" name="name" value="{{ old('name') }}"> @error('name') <span style="color: red; font-size: 0.9em;">{{ $message }}</span> @enderror <label>Email:</label> <input type="email" name="email" value="{{ old('email') }}"> @error('email') <span style="color: red; font-size: 0.9em;">{{ $message }}</span> @enderror

🔄 Repopulating Forms with old()

old() helper retrieves previously submitted values, so users don't have to re-type everything when validation fails.

<input type="text" name="name" value="{{ old('name') }}"> <input type="email" name="email" value="{{ old('email') }}"> <textarea name="message">{{ old('message') }}</textarea> <!-- For select dropdown --> <select name="country"> <option value="nigeria" {{ old('country') == 'nigeria' ? 'selected' : '' }}>Nigeria</option> <option value="ghana" {{ old('country') == 'ghana' ? 'selected' : '' }}>Ghana</option> </select> <!-- For checkboxes --> <input type="checkbox" name="agree" {{ old('agree') ? 'checked' : '' }}> I agree

💻 Complete Registration Form Example

Route:

Controller:

<?php // app/Http/Controllers/RegisterController.php namespace App\Http\Controllers; use Illuminate\Http\Request; class RegisterController extends Controller { public function show() { return view('register'); } public function store(Request $request) { $validated = $request->validate([ 'name' => 'required|min:3|max:50|alpha', 'email' => 'required|email|unique:users', 'phone' => 'required|numeric|min:10', 'password' => 'required|min:8|confirmed', 'age' => 'required|numeric|min:18|max:100', 'gender' => 'required|in:male,female', 'agree' => 'required', ]); // Save to database (we'll learn this next week) // For now, just show success return redirect('/register')->with('success', 'Registration successful!'); } } ?>

📋 Custom Validation Messages

<?php $validated = $request->validate([ 'name' => 'required|min:3', 'email' => 'required|email', ], [ 'name.required' => 'Please enter your name.', 'name.min' => 'Name must be at least 3 characters.', 'email.required' => 'Email address is required.', 'email.email' => 'Please enter a valid email address.', ]); ?>

🎯 Method Spoofing (PUT/DELETE)

HTML forms only support GET and POST. For PUT/PATCH/DELETE, use @method directive.

<!-- Update form (PUT) --> <form action="/students/{{ $id }}" method="POST"> @csrf @method('PUT') <!-- form fields --> <button type="submit">Update</button> </form> <!-- Delete form --> <form action="/students/{{ $id }}" method="POST"> @csrf @method('DELETE') <button type="submit">Delete</button> </form>

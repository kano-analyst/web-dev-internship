📦 What are Functions?

Functions are reusable blocks of code that perform specific tasks. They help organize code, reduce repetition, and make programs easier to maintain.

🔧 Built-in PHP Functions

String Functions

<?php $text = "Hello World"; // String length echo strlen($text); // 11 // Convert to uppercase echo strtoupper($text); // HELLO WORLD // Convert to lowercase echo strtolower($text); // hello world // Replace text echo str_replace("World", "PHP", $text); // Hello PHP // Substring echo substr($text, 0, 5); // Hello // Trim whitespace $name = " Ahmad "; echo trim($name); // Ahmad ?>

Array Functions

<?php $numbers = [5, 2, 8, 1, 9]; // Count elements echo count($numbers); // 5 // Sort array sort($numbers); print_r($numbers); // [1, 2, 5, 8, 9] // Add element array_push($numbers, 10); // Remove last element array_pop($numbers); // Check if value exists if (in_array(5, $numbers)) { echo "5 is in the array"; } // Get maximum value echo max($numbers); // 9 // Get minimum value echo min($numbers); // 1 ?>

Math Functions

<?php // Absolute value echo abs(-15); // 15 // Round number echo round(4.6); // 5 echo round(4.3); // 4 // Square root echo sqrt(16); // 4 // Power echo pow(2, 3); // 8 (2³) // Random number echo rand(1, 100); // Random between 1 and 100 // Ceiling (round up) echo ceil(4.2); // 5 // Floor (round down) echo floor(4.8); // 4 ?>

Date & Time Functions

<?php // Current date echo date("Y-m-d"); // 2025-12-06 // Current time echo date("H:i:s"); // 14:30:45 // Full date format echo date("l, F j, Y"); // Friday, December 6, 2025 // Day of week echo date("l"); // Friday // Month name echo date("F"); // December ?>

✍️ User-Defined Functions

Basic Function

<?php // Function without parameters function greet() { echo "Hello, welcome to PHP!"; } // Call the function greet(); // Hello, welcome to PHP! ?>

Function with Parameters

<?php // Function with one parameter function greetUser($name) { echo "Hello, " . $name . "!"; } greetUser("Ahmad"); // Hello, Ahmad! greetUser("Fatima"); // Hello, Fatima! // Function with multiple parameters function addNumbers($a, $b) { echo $a + $b; } addNumbers(10, 5); // 15 ?>

Function with Return Value

<?php // Return a value function multiply($x, $y) { return $x * $y; } $result = multiply(5, 4); echo $result; // 20 // Use in expression $total = multiply(3, 7) + 10; echo $total; // 31 ?>

Function with Default Parameters

<?php function createGreeting($name, $title = "Mr.") { return $title . " " . $name; } echo createGreeting("Ahmad"); // Mr. Ahmad echo createGreeting("Fatima", "Miss"); // Miss Fatima ?>

🎯 Practical Function Examples

1. Calculator Functions

<?php function add($a, $b) { return $a + $b; } function subtract($a, $b) { return $a - $b; } function multiply($a, $b) { return $a * $b; } function divide($a, $b) { if ($b == 0) { return "Cannot divide by zero!"; } return $a / $b; } // Use the functions echo "10 + 5 = " . add(10, 5) . "<br>"; echo "10 - 5 = " . subtract(10, 5) . "<br>"; echo "10 × 5 = " . multiply(10, 5) . "<br>"; echo "10 ÷ 5 = " . divide(10, 5) . "<br>"; ?>

2. Validation Functions

<?php // Check if email is valid function isValidEmail($email) { return filter_var($email, FILTER_VALIDATE_EMAIL); } // Check if password is strong function isStrongPassword($password) { return strlen($password) >= 8; } // Check if age is valid function isValidAge($age) { return $age >= 18 && $age <= 100; } // Usage if (isValidEmail("test@example.com")) { echo "Valid email"; } if (isStrongPassword("mypass123")) { echo "Strong password"; } ?>

3. Formatting Functions

<?php // Format currency function formatCurrency($amount) { return "₦" . number_format($amount, 2); } // Format phone number function formatPhone($phone) { return substr($phone, 0, 4) . "-" . substr($phone, 4, 3) . "-" . substr($phone, 7); } // Truncate text function truncateText($text, $length = 50) { if (strlen($text) > $length) { return substr($text, 0, $length) . "..."; } return $text; } echo formatCurrency(15000); // ₦15,000.00 echo formatPhone("08012345678"); // 0801-234-5678 ?>

🔄 Variable Scope

<?php $globalVar = "I am global"; function testScope() { $localVar = "I am local"; echo $localVar; // Works // To access global variable global $globalVar; echo $globalVar; // Now works } testScope(); echo $localVar; // Error: undefined variable ?>

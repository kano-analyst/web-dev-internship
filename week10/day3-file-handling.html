📁 File Functions in PHP

Function Description Usage
fopen() Opens a file fopen("file.txt", "r")
fread() Reads from a file fread($file, filesize("file.txt"))
fwrite() Writes to a file fwrite($file, $data)
fclose() Closes a file fclose($file)
file_get_contents() Reads entire file file_get_contents("file.txt")
file_put_contents() Writes to file file_put_contents("file.txt", $data)

📖 File Open Modes

Mode Description
r Read only, pointer at beginning
w Write only, erases existing content
a Append, pointer at end
r+ Read/Write, pointer at beginning
w+ Read/Write, erases existing content
a+ Read/Append, pointer at end

📝 Writing to Files

Method 1: Using fopen/fwrite/fclose

<?php // Open file for writing $file = fopen("data.txt", "w"); // Write data $text = "Hello, this is a test file!\n"; $text .= "PHP file handling is fun!"; fwrite($file, $text); // Close file fclose($file); echo "File written successfully!"; ?>

Method 2: Using file_put_contents (Easier)

<?php $text = "Hello, this is a test file!\n"; $text .= "PHP file handling is fun!"; file_put_contents("data.txt", $text); echo "File written successfully!"; ?>

📖 Reading from Files

Method 1: Using fopen/fread/fclose

<?php // Open file for reading $file = fopen("data.txt", "r"); // Read file content $content = fread($file, filesize("data.txt")); // Close file fclose($file); echo $content; ?>

Method 2: Using file_get_contents (Easier)

<?php $content = file_get_contents("data.txt"); echo $content; ?>

➕ Appending to Files

<?php // Append new data to existing file $newData = "\nThis line is appended!"; // Method 1: fopen with 'a' mode $file = fopen("data.txt", "a"); fwrite($file, $newData); fclose($file); // Method 2: file_put_contents with FILE_APPEND flag file_put_contents("data.txt", $newData, FILE_APPEND); echo "Data appended successfully!"; ?>

📋 Working with CSV Files

Writing to CSV

<?php $students = [ ["Ahmad", "ahmad@email.com", "20"], ["Fatima", "fatima@email.com", "22"], ["Ibrahim", "ibrahim@email.com", "21"] ]; $file = fopen("students.csv", "w"); // Write header fputcsv($file, ["Name", "Email", "Age"]); // Write data rows foreach ($students as $student) { fputcsv($file, $student); } fclose($file); echo "CSV file created successfully!"; ?>

Reading from CSV

<?php $file = fopen("students.csv", "r"); echo "<table border='1'>"; while (($row = fgetcsv($file)) !== false) { echo "<tr>"; foreach ($row as $cell) { echo "<td>" . $cell . "</td>"; } echo "</tr>"; } echo "</table>"; fclose($file); ?>

✅ Best Practices

  • ✓ Always close files after opening them
  • ✓ Check if file exists before reading
  • ✓ Use FILE_APPEND to add to existing files
  • ✓ Validate data before writing to files
  • ✓ Use CSV for structured data
  • ✓ Sanitize data with htmlspecialchars()

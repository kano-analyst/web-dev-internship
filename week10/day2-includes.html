📂 Include vs Require

Statement Description On Error
include Includes file, continues if file not found Warning (script continues)
include_once Includes file only once Warning (script continues)
require Requires file, stops if file not found Fatal error (script stops)
require_once Requires file only once Fatal error (script stops)

🏗️ Project File Structure

my-website/ │ ├── includes/ │ ├── header.php │ ├── footer.php │ ├── nav.php │ └── config.php │ ├── css/ │ └── style.css │ ├── images/ │ └── logo.png │ ├── index.php ├── about.php ├── contact.php └── services.php

📝 Creating Reusable Components

1. Header Component (includes/header.php)

<!-- includes/header.php --> <!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title><?php echo $pageTitle; ?></title> <link rel="stylesheet" href="css/style.css"> </head> <body> <header> <div class="container"> <h1>My Website</h1> <p>Welcome to our amazing site</p> </div> </header>

2. Navigation Component (includes/nav.php)

<!-- includes/nav.php --> <nav> <ul> <li><a href="index.php">Home</a></li> <li><a href="about.php">About</a></li> <li><a href="services.php">Services</a></li> <li><a href="contact.php">Contact</a></li> </ul> </nav>

3. Footer Component (includes/footer.php)

<!-- includes/footer.php --> <footer> <div class="container"> <p>© 2025 My Website. All rights reserved.</p> <p>Built with PHP</p> </div> </footer> </body> </html>

4. Config File (includes/config.php)

<?php // includes/config.php // Site configuration define('SITE_NAME', 'My Website'); define('SITE_EMAIL', 'info@mywebsite.com'); define('SITE_PHONE', '080-123-4567'); // Database configuration define('DB_HOST', 'localhost'); define('DB_USER', 'root'); define('DB_PASS', ''); define('DB_NAME', 'my_database'); // Paths define('BASE_URL', 'http://localhost/my-website/'); define('UPLOAD_DIR', 'uploads/'); ?>

🔗 Using Includes in Pages

Homepage (index.php)

<?php $pageTitle = "Home - My Website"; include 'includes/header.php'; include 'includes/nav.php'; ?> <main> <div class="container"> <h2>Welcome to Our Homepage</h2> <p>This is the main content of the homepage.</p> </div> </main> <?php include 'includes/footer.php'; ?>

About Page (about.php)

<?php $pageTitle = "About Us - My Website"; include 'includes/header.php'; include 'includes/nav.php'; ?> <main> <div class="container"> <h2>About Us</h2> <p>Learn more about our company and mission.</p> </div> </main> <?php include 'includes/footer.php'; ?>

✅ Best Practices

  • ✓ Use require_once for critical files (config, database)
  • ✓ Use include for optional components
  • ✓ Keep includes in a separate folder
  • ✓ Use relative paths consistently
  • ✓ Don't repeat code - create reusable components

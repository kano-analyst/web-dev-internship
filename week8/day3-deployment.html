🐛 Debugging Tips

Open Browser Developer Tools (F12)

  • Console: Check for JavaScript errors (red text)
  • Elements: Inspect HTML structure and CSS
  • Network: Verify Bootstrap CSS/JS are loading
  • Responsive Mode: Test different screen sizes

Common Errors & Fixes

// Error: Function not defined // Fix: Make sure function is declared before calling // Error: Cannot read property of null // Fix: Verify ID names match between HTML and JavaScript // Error: Styles not applying // Fix: Check CSS file path, verify link tag in HTML // Error: Bootstrap not working // Fix: Verify CDN links, check internet connection

🚀 Deploy to GitHub Pages

Step 1: Create GitHub Repository

  1. Go to github.com
  2. Click "New Repository" (green button)
  3. Name: todo-list-app
  4. Description: "My To-Do List Application"
  5. Public repository
  6. Click "Create Repository"

Step 2: Initialize Git Locally

# Navigate to your project folder cd todo-list-app # Initialize Git repository git init # Add all files git add . # Commit files git commit -m "Initial commit: To-Do List App"

Step 3: Push to GitHub

# Add remote repository git remote add origin https://github.com/YOUR-USERNAME/todo-list-app.git # Push to GitHub git branch -M main git push -u origin main

Step 4: Enable GitHub Pages

  1. Go to your repository on GitHub
  2. Click "Settings" tab
  3. Scroll to "Pages" section (left sidebar)
  4. Under "Source", select "main" branch
  5. Click "Save"
  6. Wait 1-2 minutes for deployment
  7. Your app will be live at: https://YOUR-USERNAME.github.io/todo-list-app/

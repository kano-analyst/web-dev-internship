📝 Project Overview

To-Do List App: A fully functional task management application where users can add tasks, mark them complete, delete them, and see their progress. This project combines everything you've learned: HTML structure, CSS styling, Bootstrap components, and JavaScript interactivity.

✨ Required Features

1. Add New Tasks

Users can type a task and add it to the list

  • Input field for task text
  • Add button to submit
  • Enter key support

2. Display Task List

Show all tasks in a clean, organized list

  • Each task shows text
  • Visual distinction between complete/incomplete
  • Responsive layout

3. Mark Tasks Complete

Click on task to toggle completion

  • Checkbox or click interaction
  • Strike-through completed tasks
  • Change visual appearance

4. Delete Tasks

Remove tasks from the list

  • Delete button for each task
  • Confirmation optional
  • Smooth removal animation

5. Task Counter

Show number of tasks and completion status

  • Total tasks count
  • Completed tasks count
  • Remaining tasks count
